## Individuell uppgift - Hälsostudie
Analysera data från datasetet health_study_dataset.csv.
Resultatet presenteras i Jupyter Notebooken healthstudy.ipynb

### Miljö

* Python: 3.13.7

## För att köra projektet
### Klona projetet
```
git clone https://github.com/Cym3ra/health_study.git
cd health_study
git checkout del2
```
## Skapa och aktivera virtuell miljö
```
python -m venv .venv
```
### Windows PowerShell
```
.venv\Scripts\Activate
```
### macOS/Linux
```
# source .venv/bin/activate
```
### För att installera nödvändiga paket:
```
pip install -r requirements.txt
```
